Copy titles and URLs from several selected tabs at once, as Markdown or another style you choose. On a single page, the same action is available from a shortcut, the right-click menu, or the toolbar.

WHAT IT DOES

- Select several tabs in the tab strip and grab them as one list from the popup
- Built-in: Markdown, plain text, HTML, reST, LaTeX
- Save up to 9 of your own styles
- Works with selected text on the page, or when you right-click an anchor
- Change the default output on the options page

HOW TO USE

1. Click the toolbar icon to grab the default output, then review or switch it in the popup
2. Right-click the extension icon or the page and pick the output you want
3. Keyboard shortcuts can be changed at chrome://extensions/shortcuts

NOTES

- With several tabs selected, each item uses that tab's title and URL. Items that cannot be read (such as chrome:// pages) are skipped
- Chrome blocks this on the Web Store site itself. Please try it on a normal website

This extension does not collect or send user data. Settings stay in the browser.
