Format Link Custom は、現在のタブのリンクをお好みの形式に整形してクリップボードにコピーする拡張機能です。Markdown・HTML・reST・Textile・LaTeX・プレーンテキストのほか、独自にカスタマイズした形式でもコピーできます。

本拡張機能は hnakamur 氏作「Format Link」のフォークで、複数タブの一括コピーなどの機能を追加しています。


■ 主な機能

- キーボードショートカット・右クリックメニュー・ツールバーボタンのいずれかで、整形済みリンクをワンアクションでコピー
- 内蔵形式: Markdown、reST、HTML、Textile、Text、LaTeX
- カスタム形式: ミニテンプレート言語で最大 9 形式まで定義可能
  - プレースホルダー: {{title}}、{{url}}、{{text}}
  - 文字列置換: 例 {{url.s("\\)","%29")}}
  - Markdown の例: [{{text.s("\\[","\\[").s("\\]","\\]")}}]({{url.s("\\)","%29")}})
- ページ上で文字列を選択している場合やリンク上で右クリックした場合は、その選択テキスト・リンク URL を使用
- 複数タブの一括コピー: タブバーで複数のタブを選択（Ctrl/Cmd クリックまたは Shift クリック）してツールバーのボタンからポップアップを開くと「Copy all selected tabs (N)」ボタンが現れ、選択したすべてのタブを 1 行に 1 リンクずつまとめてコピー
- オプションページでデフォルトの形式を変更できます


■ 使い方

1. キーボードショートカット（chrome://extensions/shortcuts で変更可能）
   - Shift+Alt+C: デフォルト形式でコピー
   - Shift+Alt+1 / Shift+Alt+2 / Shift+Alt+3: 形式 1 / 2 / 3 でコピー
2. 右クリックメニュー
   - 右クリックして使いたい形式を選択。設定済みの形式ごとにメニュー項目（例: 「as Markdown」）が表示されます
3. ツールバーボタン
   - ツールバーのボタンをクリックするとデフォルト形式でコピーし、コピー内容を表示するポップアップが開きます。別の形式に切り替えてコピーし直すこともできます


■ ご注意

- Chrome では拡張機能ごとに最大 4 件までしかショートカットを割り当てられないため、形式 4〜9 にはショートカットがありません
- 複数タブモードでは {{text}} がタブタイトル、{{url}} がタブ URL を意味し、ページ上の選択テキストやリンクは使用しません。アクセスできないタブ（chrome:// ページなど）はスキップされます
- セキュリティ上の理由により、Chrome ウェブストアなど一部のページではコピーできません


■ 権限について

- 「すべてのサイトで自分のデータを読み取って変更する」: 閲覧中のページからページタイトル・URL・選択テキスト・リンク URL を取得するためのコンテンツスクリプトを実行するために必要です
- 「コピー＆ペーストしたデータの変更」（clipboardWrite）: 整形したテキストをクリップボードにコピーするために必要です
- 「コンテキストメニュー」（contextMenus）: 「Format Link」のメニュー項目を追加するために必要です
- 「ストレージ」（storage）: 設定をローカルに保存するために必要です

本拡張機能はユーザーのデータを収集・送信しません。設定とコピーしたテキストはすべてブラウザ内に留まります。
