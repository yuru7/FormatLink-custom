選択した複数のタブから、タイトルと URL を Markdown などでまとめてクリップボードへコピーします。1 ページだけでも、ショートカット・右クリック・ツールバーから同じ操作ができます。

■ できること

- タブバーでいくつか選ぶと、ポップアップから一覧として一度に取得できます
- 内蔵: Markdown、Text、HTML、reST、LaTeX
- 自分で定義した書式を最大 9 件まで保存できます
- ページ内の選択文字列や、ページ上のリンクを右クリックしたときにも使えます
- 既定の出力はオプション画面で変更できます

■ 使い方

1. ツールバーをクリックすると既定の出力で取得し、内容の確認と切り替えができます
2. 拡張機能アイコンまたはページを右クリックして、使いたい出力を選びます
3. キーボード操作は chrome://extensions/shortcuts で変更できます

■ 補足

- 複数選択時は各タブのタイトルと URL を使います。chrome:// など取得できないものは除きます
- Chrome の制限により、ウェブストア自身のページでは動きません。確認は通常のウェブサイトで行ってください

ユーザーのデータは収集・送信しません。設定はブラウザ内だけに保存されます。
