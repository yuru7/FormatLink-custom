Format Link Custom 手動テスト

下の文章を選択して、拡張機能のポップアップ、ショートカット、または コンテキストメニューからリンクをコピーしてください。

1. iframeなし

iframeを使わない親ページの選択テキストです。 親ページのリンク

期待値: 選択文字列がリンクテキストになり、URLは親ページのURLになります。

2. 同一オリジン iframe

親ページと同じポートのiframeです。

期待値: iframe内の選択文字列がリンクテキストになります。

3. クロスオリジン iframe

ポートが異なるため、親ページとは別オリジンのiframeです。

期待値: クロスオリジンでもiframe内の選択文字列がリンクテキストになります。

確認手順

  1. 各領域の文章を一部選択します。
  2. ツールバーボタンを押し、ポップアップに選択文字列が表示されることを確認します。
  3. 同じ選択状態でショートカットを実行して確認します。
  4. リンク上で右クリックし、コンテキストメニューからコピーして確認します。
  5. リンクを選択した場合は、選択範囲内のリンクURLが使われることを確認します。

iframe内のテキストがページタイトルに置き換わる場合は、拡張機能を再読み込みしてから ページも再読み込みしてください。
